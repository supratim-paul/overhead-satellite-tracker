# Overhead: live satellite tracker

Real-time 3D tracker for up to 10,000+ satellites. Orbits are propagated in the browser with SGP4, drawn on a CesiumJS globe with day/night imagery, and any satellite can be opened as an animated 3D model.

**Live demo:** https://YOUR-APP.onrender.com  ·  **Screenshot:** add `docs/screenshot.png` and embed it here

## Features
- Live positions for Stations, Starlink, GPS, Weather, Science, Geostationary and All active groups
- Click or search a satellite: altitude, speed, lat/lon, orbit ring, and an animated 3D model with a close-up follow camera
- Pass prediction for your location (next 24 h, above 10°) with browser notification alerts
- Realistic globe: satellite imagery, NASA night lights, atmosphere, sun and moon on the real clock
- Hover and touch animations, responsive layout, reduced-motion support

## How it works
- **Frontend** (React, Vite, CesiumJS, satellite.js): SGP4 runs in a Web Worker so 10k+ satellites update every second without blocking the UI.
- **Backend** (FastAPI): fetches TLEs from CelesTrak, caches them in memory and on disk (2 h, matches CelesTrak's update rate), falls back to stale data if the source fails, and stores every new TLE in SQLite.
- **No external services:** no Docker, Redis or Postgres.

## Run locally
Needs Python 3.10+ and Node.js 18+.

    npm run dev      # hot reload, http://localhost:5173
    npm start        # production build, http://localhost:8000

Tests: `pip install -r backend/requirements-dev.txt && pytest backend`

3D models are generated by `python tools/make_models.py`.

## Deploy
If the host cannot reach CelesTrak (it can be blocked on cloud servers), run `python tools/snapshot.py` on your own computer, commit `backend/seed/*.json` and push. The app falls back to it.
`frontend/dist` is committed, so hosts only need Python. Push to GitHub, then Render > New > Blueprint (uses `render.yaml`). Rebuild first after frontend edits: `cd frontend && npm run build`.
Keep the free tier awake by pinging `/api/health` every 10 minutes (e.g. UptimeRobot).
